🧰 **Marcel Toolbox**
The DesignOps companion for Figma teams building with the Marcel Design System. Marcel Toolbox follows the designer's real workflow in three moments — **Je démarre · Je construis · Je livre** — so every file stays clean, consistent, and ready to hand off.

🚀 **Je démarre — One-Click Starter Kit**
Generate a fully structured workspace instantly, with real DS components, based on the [Statut] Template Delivery [Produit] [NS] and the Domaine Design System Template. Already have content? Run a structure audit and apply the missing pages — nothing changes without your consent.

🔍 **Je construis — Unified Quality Check**
One scan, one 0–100 score, one actionable list. Marcel audits naming, colors, typography, spacing, components, and DS coverage in a single pass, then fixes what it can: renames vague layers, binds the right Marcel variables and text styles, re-attaches detached instances. Scan a selection, a page, or the whole file. Ignore what's intentional and re-score without a rescan.

🧹 **Style Cleaner**
Find dead local styles and variables, plus foreign bindings from non-DS libraries. Detach, replace with the nearest Marcel token, or delete — one by one or in batch.

🖼️ **Smart Cover Updater**
Swap the cover component in place to keep project status and metadata up to date in one click, from In Progress to Source of Truth.

📦 **Je livre — Delivery Gate**
Check the handoff conditions in one place: Quality Check score against your project profile's threshold, accessibility check attested, cover up to date. Stamp the file with a Delivery Quality Check badge, copy the summary for Jira, and mark the cover as Design Done.

Available in French, English, and Brazilian Portuguese.

Built for Product Designers who prioritize consistency, clean file architecture, and scalable design practices.
